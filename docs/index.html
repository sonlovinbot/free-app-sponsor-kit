🗺 Quy trình 7 bước

Claude chỉ hỏi những gì không tự suy ra được từ code, và dừng lại xin xác nhận trước mọi việc ra bên ngoài (tạo repo công khai, push, phát hành).

Hỏi đáp với người tạo

Tên app, tài khoản GitHub, công khai hay riêng tư, dự án gốc và giấy phép, nhà tài trợ, dữ liệu người dùng lưu ở đâu — gom một lần, ghi vào SHIP.md.

Dọn repo

Bỏ tài liệu, ví dụ, test, CI thừa của dự án gốc và thư viện nặng không dùng; giữ LICENSE và ghi nhận tác giả. Cài mới từ zip để chắc vẫn chạy.

Kiểm tra bảo mật & bản quyền

Quét khoá API, token, file bí mật — cả trong lịch sử git; dữ liệu cá nhân trong ảnh và log; giấy phép. Còn lỗi đỏ thì không push.

Đóng gói & phát hành

Zip cho từng hệ điều hành, lệnh cài 1 dòng (Terminal / PowerShell) không bị chặn, GitHub Releases với link tải luôn trỏ bản mới nhất.

README & trang giới thiệu

Trang GitHub Pages có video nhúng, ảnh chụp từ bản sạch (không lộ dữ liệu riêng), nút tải trực tiếp, mục "Không cài được?".

Giao diện & lần dùng đầu

Onboarding kiểm tra cấu hình máy, độ tương phản chữ, màn hình laptop và điện thoại, font có dấu tiếng Việt.

Sau phát hành

Báo bản mới và quảng cáo từ xa, kiểm tra mọi link tải / trang / thông báo đều chạy, ghi bài học mới.

🛡 Kiểm tra bảo mật trước khi chia sẻ

Một lệnh, báo 🔴 phải sửa · 🟡 xem lại · 🟢 ổn. Chạy được độc lập, không cần Claude.

Quét những gì

  • Khoá OpenAI, Anthropic, Hugging Face, GitHub, AWS, Google, Slack, khoá riêng tư, JWT
  • Lịch sử git — khoá đã xoá khỏi file vẫn lấy lại được
  • File .env, .pem, credentials, file phiên của công cụ AI
  • Đường dẫn máy cá nhân, email, file quá lớn
  • LICENSE, ghi nhận tác giả gốc, giấy phép GPL

💌 Góc tài trợ minh bạch

Phần mềm miễn phí vẫn cần kinh phí. Một thẻ nhỏ có nhãn rõ ràng, nút (i) mở thư ngỏ nói thật với người dùng — không popup, không theo dõi.

🌐 Tên miền riêng cho mọi dự án — miễn phí trên GitHub

Có một tên miền (vd tenban.com) là đủ: mọi dự án dùng chung một địa chỉ đẹp app.tenban.com/<tên-dự-án>, có HTTPS, không tốn thêm đồng nào. Website đang chạy ở tên miền gốc không bị ảnh hưởng.

Xác minh tên miền gốc với GitHub

GitHub → Settings → Pages → Add a domain → nhập tenban.com → thêm bản ghi TXT GitHub đưa (tên dạng _github-pages-challenge-<tài-khoản>) ở nơi quản lý tên miền → bấm Verify. Xác minh tên miền gốc là đủ cho mọi tên miền con.

Trỏ tên miền con về GitHub

Thêm bản ghi CNAME: tên app → giá trị <tài-khoản>.github.io. Không đụng bản ghi A của tên miền gốc.

Tạo repo trang chủ

Repo tên đặc biệt <tài-khoản>.github.io (công khai), có file CNAME chứa app.tenban.com và một trang tổng hợp dự án. Settings → Pages → Custom domain → app.tenban.com.

Bật HTTPS

Chờ GitHub cấp chứng chỉ (vài phút tới 1 giờ) rồi tick Enforce HTTPS. Chứng chỉ Let's Encrypt, tự gia hạn.

Mọi dự án tự có địa chỉ

Repo nào bật Pages đều tự chạy ở app.tenban.com/<tên-repo>/; link <tài-khoản>.github.io/… cũ tự chuyển hướng sang.

❓ Hỏi nhanh

Có cần biết code không?
Không bắt buộc. Claude đọc code, làm các bước và giải thích bằng tiếng Việt. Bạn chỉ trả lời vài câu (tên app, tài khoản, công khai hay riêng tư) và bấm xác nhận khi Claude sắp làm việc ra bên ngoài.
Dùng cho loại phần mềm nào?
App chạy trên máy (Python, Node, Electron…), website tĩnh, game web 3D, công cụ nội bộ — miễn là bạn muốn chia sẻ miễn phí. Góc tài trợ dùng được cho cả app local (đọc thông báo khi có mạng) lẫn website.
Kiểm tra bảo mật có đảm bảo an toàn tuyệt đối?
Không công cụ nào hứa được điều đó. Bộ kit quét các lỗi hay gặp nhất (khoá lộ, file bí mật, dữ liệu cá nhân, giấy phép) và báo rõ đã kiểm những gì; phần còn lại Claude soát bằng mắt theo danh sách.
Có bắt buộc gắn quảng cáo không?
Không. Hai skill độc lập — chỉ dùng quy trình phát hành, hoặc chỉ dùng thanh "Đã có bản mới" mà không có quảng cáo.
